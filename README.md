# Melody — A Little Love Story

A three-page romantic website for GitHub Pages.

## Files
- `index.html` — welcome page
- `letter.html` — love letter
- `memories.html` — photo memories
- `assets/images/memory-1.jpg` through `memory-4.jpg` — replace with your photos

## Song
The music link on all three pages opens Chris Grey's official lyric video for **LET THE WORLD BURN** on YouTube. Playback takes place on YouTube; it does not autoplay, and it may restart when navigating between pages.

## Add your photos
Upload four pictures into `assets/images/` and name them exactly:
- `memory-1.jpg`
- `memory-2.jpg`
- `memory-3.jpg`
- `memory-4.jpg`

For PNG images, either convert them to JPG or update the matching image filename in `memories.html`.

## Publish on GitHub Pages
1. Create a GitHub repository, for example `melody-love-website`.
2. Upload all files and folders from this project. Keep the folder structure unchanged.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select **main** and **/(root)**, then Save.
6. Wait for GitHub Pages to publish. Your site will be at `https://YOUR-USERNAME.github.io/melody-love-website/`.

Use the repository's actual name and your GitHub username in the URL.
